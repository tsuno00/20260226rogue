# ローグライクゲーム 設計書

作成日: 2026-02-26

## 概要

ブラウザで動作する単一フロアのローグライクゲーム。
`index.html` + `style.css` + `game.js` の3ファイル構成。

## ユーザー要件

- 表示方式: 絵文字タイル
- 操作: キーボード（矢印キー / WASD）
- コンテンツ量: ミニマル（単一フロア）
- リプレイ: パーマデス（死亡即リセット）

## アーキテクチャ

```
index.html   — 画面構造（グリッド表示エリア・UIパネル）
style.css    — レイアウト・グリッドスタイル・フォント
game.js      — ゲームロジック全体（単一ファイル・クラス構成）
```

### `game.js` 内部構成

| クラス | 責務 |
|--------|------|
| `MapGenerator` | ランダム矩形配置（試行回数上限あり）・通路接続 |
| `Entity` | プレイヤー・敵の共通クラス（位置・HP・ATK・DEF） |
| `Game` | 状態管理・ターン制御・入力処理 |
| `Renderer` | DOM更新（絵文字グリッド描画・UIパネル更新） |

## マップ仕様

- グリッドサイズ: 40×25マス
- 部屋数: 4〜6個、ランダム配置
- 接続: 部屋同士を通路でつなぐ

### 絵文字割り当て

| 種類 | 絵文字 |
|------|--------|
| プレイヤー | 🧑 |
| 壁 | 🧱 |
| 床 | ⬛ |
| 敵（スライム） | 🟢 |
| 敵（コウモリ） | 🦇 |
| 敵（ボス） | 💀 |
| 回復薬 | 🧪 |
| 武器 | ⚔️ |
| ゴール（ボス討伐） | — |

## 戦闘システム

- ターン制: プレイヤー行動 → 全敵行動
- 戦闘発生: 隣接マスに敵がいる方向にキー入力で攻撃
- ダメージ計算: `max(1, ATK - 相手DEF)`
- 敵AI: 視野5マス内ならプレイヤー追尾、それ以外はランダム歩行

## プレイヤーステータス（初期値）

| 項目 | 値 |
|------|----|
| HP | 20 |
| ATK | 3 |
| DEF | 1 |
| Gold | 0 |

## アイテム

| アイテム | 効果 |
|----------|------|
| 🧪 回復薬 | HP+5 |
| ⚔️ 武器 | ATK+2 |

## 勝敗条件

- **勝利**: ボス（💀）を倒す → ゲームクリア画面
- **敗北**: HP=0 → ゲームオーバー → 即リセット（パーマデス）
